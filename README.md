# 来去有数 小程序

第一版可运行骨架，数据先存在本机，后续接入微信云开发做跨设备同步。

## 打开方式

1. 安装微信开发者工具稳定版
2. 导入项目，选择本文件夹 `laiquyoushu-miniprogram`
3. AppID 先用项目默认的游客模式（touristappid），或替换成你公众平台的正式 AppID
4. 编译后即可在模拟器里记账、看明细和统计

## 页面

- 记一笔：支出/收入、金额、分类、日期、备注
- 明细：按月查看流水，可删除记录
- 统计：月度收入/支出/结余 + 支出分类占比
- 我的：导出 JSON、清空数据、版本信息
